2026-11-23. `paper/assay.pdf`, built from commit 9efd2a9, is Zenodo record 24454920, DOI
10.5281/zenodo.24454920; the DOI for all versions is 10.5281/zenodo.24454919.

- **The deposit.** Created 2026-11-23 at 05:19 UTC (Zenodo's own timestamp) and published the same day by the

  public (the push of that commit to `main`). The file is 128,222 bytes with md5

  the Hugging Face corpus dataset and demo Space); and the 21 arXiv works the paper cites.
- **In the repository.** `CITATION.cff` and the README now name the DOI. `.zenodo.json` is unchanged. The tag
  `paper-v1.0` marks the commit the PDF was built from, and the GitHub release carries the same file.
- **Not the registration.** The deposit dates nothing about the four pre-registrations. Their order is the git
  history of `docs/PRE-REGISTRATION*.md` against the code they register, checked by `tests/test_paper.py`, and those
  are commits by the same author with no outside timestamp.
- **Reversal.** The file on the record cannot change; its metadata can. A later entry corrects any statement on
  the record found wrong, and a corrected paper goes up as a new version under the same concept DOI.
