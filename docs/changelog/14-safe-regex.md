The capability is the point; the exposure is the bug. |
| Slice 13c | `safe_regex.search` runs the match in a subprocess under a wall clock. | `tests/test_safe_regex.py` exhibits the hang and asserts it is bounded | **Kept.** Same boundary `sandbox.py` already draws around untrusted environment code — a timeout is only enforceable where something can kill what overran. No new dependency, ~30ms per call. A slow pattern raises rather than returning False: returning False would let a hostile pattern silently mark every item wrong, which is a defect wearing a verifier's clothes. |
